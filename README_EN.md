# Tianye Game Center

An Electron + HTML5 game collection featuring a variety of web-based mini games.

[中文文档](README.md)

## Included Games

> 🎖 **Flagship: Land & Air Combat (War Thunder-like)** — 63 vehicles (tanks/planes/helicopters across 6 tiers), realistic ballistics & armor (ricochet/ammo rack/module damage), host-authoritative online PvP, and **trainable AI agents** (behavior cloning + DAgger + PPO that outperform the rule-based AI). Play online: [xiaotuling.com](https://xiaotuling.com)

## Tech Stack

- **Electron** - Desktop app packaging
- **Three.js** - 3D rendering
- **p5.js** - 2D rendering
- **Vanilla HTML5 / CSS / JavaScript** - Frontend

## Getting Started

### Web Version

Play online: [https://xiaotuling.com](https://xiaotuling.com) (all games + online multiplayer)

Or open `index.html` in your browser to play the Tianye Space Program.

### Desktop Version (Game Center)

```bash
cd app
npm install
npm start
```

## Build

```bash
# Windows
npm run build

# macOS
npm run build:mac
```
