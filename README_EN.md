## Tech Stack

- **Electron** - Desktop app packaging
- **Three.js** - 3D rendering
- **p5.js** - 2D rendering
- **Vanilla HTML5 / CSS / JavaScript** - Frontend

## Getting Started

### Web Version

Open `index.html` in your browser to play the Tianye Space Program.

### Desktop Version (Game Center)

```bash
cd app
npm install
npm start
```

## Build

```bash
# Windows
npm run build

# macOS
npm run build:mac
```
