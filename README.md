# 天业游戏中心 (Tianye Game Center)

## 技术栈

- **Electron** - 桌面应用打包
- **Three.js** - 3D 渲染
- **p5.js** - 2D 渲染
- **原生 HTML5 / CSS / JavaScript** - 前端

## 运行方式

### 网页版

直接在浏览器中打开 `index.html` 即可体验天业太空计划。

### 桌面版（游戏中心）

```bash
cd app
npm install
npm start
```

## 打包

```bash
# Windows
npm run build

# macOS
npm run build:mac
```
