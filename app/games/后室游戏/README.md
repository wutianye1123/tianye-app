# 后室 - The Backrooms

一个基于经典后室都市传说的第一人称恐怖游戏。

## 游戏介绍

如果你不小心从现实中跌落出来，你最终会来到后室。这里是一个无尽的迷宫，有着黄色的墙壁、嗡嗡作响的荧光灯和潮湿的地毯...

## 游戏特性

- **Level 0 风格场景**：经典的后室黄色墙壁、荧光灯和潮湿地毯
- **程序化迷宫生成**：每次游戏都是不同的迷宫布局
- **第一人称控制**：沉浸式的第一人称视角
- **实体追踪系统**：有一个怪物在追逐你
- **恐怖氛围**：荧光灯闪烁、环境音效、迷雾效果
- **生存机制**：体力和理智系统

## 控制方式

| 按键 | 动作 |
|------|------|
| W/A/S/D | 移动 |
| 鼠标 | 视角控制 |
| Shift | 奔跑（消耗体力） |
| F | 切换手电筒 |

## 游戏提示

1. **不要奔跑太久**：奔跑会消耗体力，体力耗尽后无法奔跑
2. **保持手电筒开启**：在黑暗中会降低理智值
3. **注意声音**：荧光灯的嗡嗡声可能会掩盖怪物的脚步声
4. **怪物会被声音吸引**：奔跑声可能会吸引实体
5. **看着怪物**：当你看着怪物时，它会停止移动

## 技术栈

- **Three.js** - 3D渲染引擎
- **Pointer Lock API** - 第一人称控制
- **Web Audio API** - 程序化音效生成
- **Canvas API** - 程序化纹理生成

## 如何运行

直接在浏览器中打开 `index.html` 文件即可开始游戏。

推荐使用现代浏览器（Chrome、Firefox、Edge）以获得最佳体验。

## 游戏机制

### 体力系统
- 奔跑会消耗体力
- 体力耗尽后需要等待恢复才能再次奔跑
- 行走时体力会自动恢复

### 理智系统
- 在黑暗中（手电筒关闭）会降低理智
- 理智过低会影响视野
- 开启手电筒可以恢复理智

### 实体行为
- 游戏开始30秒后实体会激活
- 实体会巡逻迷宫
- 当实体看到玩家时会开始追逐
- 玩家看着实体时，实体会停止移动
- 实体会记住玩家最后的位置并前往搜索

## 关于后室

后室是一个网络都市传说，描述了一个在现实之外的超空间。当你"卡出"现实世界时，就会掉落到这里。

Level 0 是后室的第一层，也是最著名的层级，特征包括：
- 约6亿平方英里的随机生成房间
- 单调的黄色壁纸
- 嗡嗡作响的荧光灯
- 潮湿地毯的气味
- 以及...其他东西

祝你好运，你可能会需要它。
