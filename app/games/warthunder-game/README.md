# 陆空对战 · 类战争雷霆（3D 网页版）

一个用 Three.js 做的单机 3D 载具对战小游戏，包含 **坦克对战** 和 **飞机对战** 两种模式。
游戏代码集中在 `js/main.js`（核心）+ `js/lib.js`（工具/纹理/地形）两个 ES module，`index.html` 只负责页面与加载——只有一份源码，不再有"打包文件 vs 源码"漂移。

## 功能一览

- **战争雷霆式操控**：坦克炮塔指哪打哪（高追随率跟光标）；飞机鼠标指哪飞哪（飞行教官自动改平）。
- **炮手瞄准镜**：Shift 进镜出黑色镜筒+密位分化；滚轮装订射距（手动补偿弹道下坠，C 回自动测距）、Z 切 4x/8x 倍率。
- **征服模式（A/B/C）**：陆战可选三点征服——三点各自独立占领，占多数点使敌方票数流失，击杀也扣票，先耗尽对方票数获胜。
- **WebAudio 合成音效**：引擎嗡鸣（音调随油门）、主炮/机枪/爆炸/导弹/命中/击杀音，全程零素材合成，按距离衰减。
- **设置面板**：音量、阴影画质、飞机 Y 反转、飞机瞄准灵敏度，存 localStorage。
- **空战提前量瞄准具**：给敌机算拦截解，屏幕上画前置瞄准圈，对准即命中。
- **坦克模块化损伤**：履带(减速)/炮管(哑火)/发动机(减速)/弹药架(殉爆)/起火，HUD 显示损坏模块，自动修复。
- **地形起伏**：噪声高度场，坦克贴地行驶、弹丸依地形爆炸、飞机撞山坠毁；顶点色（绿谷棕峰）。
- **载具外观**：梯形后掠上反角机翼、流线座舱、螺旋桨整流罩、加力焰、翼尖灯、翼下挂架；Canvas 迷彩涂装；坦克加减速俯仰/转向侧倾 + 履带差速滚动。
- **天空**：渐变天穹 + 散落云团。
- **AI**：坦克交战绕环带机动（22~46m 切向绕侧翼、远距斜接近、近距斜脱离），炮塔独立瞄准；抢点冲进圈驻守；卡死自动倒车甩头脱困；低血倒车撤退，飞机低血侧滑规避；敌方/队友按队伍区分强弱。
- **炮击手感**：主炮曳光（叠加发光长光条）、开炮后坐（欠阻尼悬挂弹簧——猛冲→过冲→回稳 ~0.5s；摇晃方向跟炮管走：朝前打抬头、侧面打侧倾；相机被推后+磕头，瞄准镜里震得更狠）。
- **战场态势**：`M` 大地图（地形底图+敌我+三点）、`Tab` 战绩板（AI 车组代号、击杀日志、票数）。
- **巷道通行**：城镇/工厂街道宽度按"楼最大跨+坦克直径+余量"生成，任何街区之间都开得过去；据点周边自动留空。
- **无尽模式**：随击杀数递增难度（敌方变多变硬），每 10 击杀出一只精英 Boss（大体型、高血高伤）。
- **小地图**：玩家居中朝上，敌红/友蓝点。
- **损伤可视化**：起火焦化冒黑烟，喷气机高空拉白色凝结尾迹。
- **移动端触控**：左半屏虚拟摇杆驾驶，右半屏拖动瞄准、按住开火。
- **进度系统**：打仗赚 💰金币 / 🔬研发点，科技树解锁更多载具。

## 运行方式

> ⚠️ 本游戏用 ES module + importmap，必须经 **HTTP 服务器** 访问，**不能直接双击 `index.html`**（`file://` 下浏览器会拦截 module 加载）。
> 桌面 app（Electron）已自带本地 HTTP 服务器，正常从启动器打开即可；独立调试请起本地服务器：

```bash
cd warthunder-game
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

Three.js 已随包附带（`three.module.js`，r160 ESM），**无需联网**。

## 操作

> 鼠标为**自由光标**（不做指针锁定），载具 / 炮塔跟随光标，准星贴在光标上。
> 坦克炮塔为战争雷霆式**指哪打哪**：高追随率跟随光标，光标到哪儿炮塔就跟到哪儿（不再慢吞吞一直转）。

### 陆战 · 坦克
| 操作 | 功能 |
|------|------|
| `W` / `S` | 前进 / 后退 |
| `A` / `D` | 车体左转 / 右转 |
| 鼠标移动 | 瞄准（炮塔偏航跟光标地面投影 + 炮管俯仰跟光标上下） |
| 鼠标左键 | 主炮开火（装填 3s，按住自动连发） |
| `1` / `2` / `3` | 切换弹种：穿甲榴弹 / 硬芯穿甲弹 / 榴弹（战争雷霆式装甲判定：正/侧/后甲等效厚度+跳弹角） |
| `空格` | 同轴机枪（高频低伤） |
| `Shift` | 按住进入炮手瞄准镜（黑色镜筒+密位分化，4x/8x 倍率，松开回第三人称） |
| `滚轮`（镜内） | 装订射距 ±10m：炮口自动上抬补偿弹道下坠（装订距离≠实际距离会打高/打低） |
| `Z`（镜内） | 切换倍率 4x ⇄ 8x |
| `C`（镜内） | 切回自动测距（按实际距离实时补偿） |
| `R` | 按住修车（原地不动，回血并修复履带 / 炮管 / 发动机模块；血满也能单修零件，主动抢修 6/s，约为被动自修的 12 倍） |
| `Esc` | 暂停 / 继续 |
| `F` | 灭火（被击中起火时使用） |
| `G` | 烟雾弹（一局 3 发）：车侧拉烟幕 12 秒，烟中的敌人 AI 无法开火 |
| `V` | 侦察标记：对准敌人按下，全队队友 AI 集火该目标 10 秒 |
| `M` | 按住看大地图：战术地图（地形起伏底图 + 敌我分布 + 征服三点归属），松开关闭 |
| `Tab` | 按住看战绩板：双方名单（AI 车组代号/击杀数/存活状态）+ 击杀日志 + 票数 |

### 空战 · 飞机
| 操作 | 功能 |
|------|------|
| 鼠标移动 | 指哪飞哪（飞行教官自动改平 / 转弯，无需手动操纵俯仰滚转） |
| `W` / `S` | 加 / 减油门 |
| `Shift` | 加力（直接拉满油门） |
| 鼠标左键 | 机炮 |
| 鼠标右键 / `X` | 导弹（仅喷气机，6 发、自动回充，会追踪锁定目标） |
| `B` | 投炸弹（仅轰炸机，8 颗、自动回充，落地范围爆炸） |
| `L` | 投核弹（仅 B-21，消耗 3 颗炸弹，超大范围毁灭） |
| `Esc` | 暂停 / 继续 |
| `F` | 灭火（起火时使用） |

击毁全部敌方目标（耗尽其票数）即胜利；玩家命数（默认 4 条）耗尽即失败。
**征服模式**（陆战/世界大战可开）：占领 A/B/C 三点，占 2 点敌方票数 2/秒流失、占 3 点 5/秒；击杀/阵亡每车扣 50 票；敌方增援与票数挂钩（票未尽援不断），先耗尽对方 500 票者获胜；敌方全灭且增援断供 6 秒即判胜（防卡局）。AI 会冲进点内驻守抢点。

## 目录结构

```
warthunder-game/
├── index.html          # 页面 + importmap + <script type="module" src="./js/main.js">
├── js/main.js          # ★核心：CONFIG / 实体 / AI / Game 引擎 / 音效 / 设置 / 菜单入口
├── js/lib.js           # 工具与资源生成器：clamp/lerp/lerpAngle + 云/天穹/迷彩/履带纹理 + terrainHeight
├── three.module.js     # Three.js r160 ESM（本地附带，离线可用）
├── css/style.css       # 菜单与 HUD 样式
├── package.json        # npm start（起本地服务器）/ npm run check（语法检查）
└── README.md
```

> 历史上这里曾有过 `js/Game.js`、`js/entities/` 等多文件 + 内联打包的双份结构，现已收敛为 `js/main.js` + `js/lib.js` 两个 ESM 模块统一维护（用原生 ESM + importmap，无需打包）。

## 嵌入到你自己的 app

最简单：把整个目录丢进你的静态服务器即可（桌面 app 用自带本地服务器加载 `index.html`）。

`Game` 是 `js/main.js` 里的核心引擎类，构造参数（供阅读源码 / 二次开发参考）：

```js
const game = new Game({
  canvas: myCanvas,          // 必填：用于渲染的 <canvas>
  mode: 'tank',              // 'tank' | 'plane'
  hudContainer: hudDiv,      // 必填：HUD 会注入此容器
  onExit: () => { ... },     // 可选：玩家点"返回主菜单"时回调
});
```

- `Game.dispose()` 会解绑所有事件监听、释放渲染器，方便在 app 里销毁。
- 平衡性参数全在 `js/main.js` 顶部的 `CONFIG`，改数值即可调难度。
- 调试：实例挂在 `window.__game`；URL 加 `?auto=tank` / `?auto=plane` 可跳过菜单直接开局（冒烟测试用）。

## 技术说明

- Three.js r160，ESM + importmap（r150 起官方不再提供 UMD 全局构建）。
- 载具用基本几何体拼搭（车体/炮塔/炮管、机身/机翼/尾翼），无需美术资源。
- 命中判定为球体距离；飞行模型为街机式（速度沿机头 + 低速下沉）。
- 起火载具会焦化冒黑烟，喷气机高油门高空时拉白色凝结尾迹。
