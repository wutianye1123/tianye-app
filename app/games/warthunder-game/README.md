# 陆空对战 · 类战争雷霆（3D 网页版）

一个用 Three.js 做的单机/联机 3D 载具对战小游戏，包含 **坦克对战** 和 **飞机对战** 两种模式（联机为混合战场）。
游戏代码集中在 `js/main.js`（核心）+ `js/lib.js`（工具/纹理/地形）+ `js/mp.js`（联机对战）三个 ES module，`index.html` 只负责页面与加载——只有一份源码，不再有"打包文件 vs 源码"漂移。

## 联机对战（PvP）

从游戏中心启动器的 **🌐 联机游戏** 进入（局域网或互联网中转房间均可），主机在游戏列表选中本游戏后点 **开始联机游戏**，所有成员会带 `?pvp=1&team=red|blue` 进入本页：

- **大厅**：显示房间成员/队伍（启动器里选红蓝队）；每人自选出战载具类别（🛡 坦克 / ✈ 飞机，型号用自己车库当前选择）；主机选地图并点 **🚀 开始对战**，全员同图开局；中途加入的玩家会自动收到战局信息直接进场。
- **规则**：坦克/飞机混合战场（统一坦克地形，**联机专属小图：半径 480m**——人少节奏快），南北双跑道机场起飞，率先 **15 杀** 的队伍获胜；阵亡 5 秒自动重生，命数无限；联机局无 AI / 无波次 / 无空投，Esc 不暂停。
- **同步架构**（详见 `js/mp.js` 头注释）：每端只模拟自己的载具，12Hz 广播状态、远端玩家为插值幽灵（复用完整载具模型/名字距离标签/血条）；开火广播为纯视觉弹；**伤害主机权威**——射手命中后上报 `wt-hit`，主机在自己的幽灵副本上跑完整装甲/跳弹/部位判定，广播 `wt-dmg`/`wt-kill` 计分，杜绝本地扣血分歧。
- Tab 战绩板 / 顶部比分横幅 / 击杀播报与单机同款。

## 功能一览

- **战争雷霆式操控**：坦克炮塔指哪打哪（高追随率跟光标）；飞机鼠标指哪飞哪（飞行教官自动改平）。
- **落点瞄准（街机导演模式）**：十字准星=炮膛射线在世界上的**真实落点**（ray 命中敌车/障碍/地形），任何距离无视差——准星贴上去就命中；红环=炮塔收敛点，重合即"炮到位"。自动测距为炮管线实测射距（不再是定值）。
- **真实弹道**：炮口速按弹种分速（穿甲榴弹 750 / 硬芯 915 / 榴弹 615 m/s）+ 真实重力 9.81，飞行时间与下坠都是真实量级；**穿深随距离衰减**（穿甲榴弹 -10%/km、硬芯 -32%/km、榴弹不衰，战雷规律）。
- **炮塔/车体分甲 + 装甲倾角**：13 型号各有车体/炮塔两套 [前/侧/后] 装甲与倾角（T-34 首上 60°、黑豹 55°、T-80U 68°、M1 75°）；总入射角=方位入射×板倾角正交合成，斜着打斜甲就**跳弹叮**（硬芯 62° 比穿甲榴弹 70° 更易跳），方盒子虎式靠厚度硬吃不跳、M1 首上正面全免疫（打车塔或绕侧）。**跳弹可见**：弹丸沿装甲法线真实弹飞（曳光甩尾+白黄火花），掉一半穿深/伤害，弹飞的流弹还能再命中别的车。
- **炮手瞄准镜**：Shift 进镜出黑色镜筒+密位分化；滚轮装订射距（手动补偿弹道下坠，C 回自动测距）、Z 切 4x/8x 倍率。
- **征服模式（A/B/C）**：陆战可选三点征服——三点各自独立占领，占多数点使敌方票数流失，击杀也扣票，先耗尽对方票数获胜。
- **WebAudio 合成音效**：引擎嗡鸣（音调随油门）、主炮/机枪/爆炸/导弹/命中/击杀音，全程零素材合成，按距离衰减。
- **设置面板**：音量、阴影画质、飞机 Y 反转、飞机瞄准灵敏度、**飞行辅助（自动改平，可关＝纯手动杆）**、胶片颗粒、**游戏节奏（正常/慢速0.5×/超慢0.25×——全世界等比变慢，战斗中即时生效）**、音乐，存 localStorage。
- **空战提前量瞄准具**：给敌机算拦截解，屏幕上画前置瞄准圈，对准即命中。目标粘性+位置阻尼（环平滑不抖不瞬移）+ 宽搜索锥（敌机刚进视野就亮环，不用手算提前量）。
- **战雷式名字距离标签**：敌我载具头顶 [代号 · 距离m]，敌红友蓝，距离越远标签越大（远处也读得清），750m 外隐藏。
- **机场起飞（空战）**：喷气机/螺旋桨机停在跑道头（带中线/边线/跑道头横杠），按住 `W` 满油门滑跑，速度够了鼠标上推（带杆）抬轮离地；方向舵滑跑转向，直升机照旧悬停出生。**联机对战为南北双跑道**（蓝军南/红军北，头朝对方），飞机同样滑跑起飞。
- **可收放起落架**：前三点式（前支柱＋左右主支柱，带斜撑/轮毂）；滑跑与低空（<12m）自动放下，离地爬升（>18m）自动收起向前折进机腹——起飞收放全自动，随机型尺寸自适应贴轮高度。
- **炮烟/爆炸/坠机特效加强**：主炮炮口烟随口径加浓；击杀爆更大+滚滚黑烟柱+地面冲击尘环；坠机双层拖烟+火花，触地大爆炸+残骸余火+碎块加倍。
- **拟真节奏（战雷式）**：出战页 `⚔ 拟真节奏` 开关——不是慢动作，是**战争雷霆式交战手感**：车体更沉（速度×0.7）、炮塔慢半拍（×0.6）、装填更长（×1.5，每一炮都要想）、命中更致命（伤害×1.35、殉爆/起火率大增）、双方更脆（先手优势大）、敌 AI 更准但不泼水；与难度叠加，持久保存。
- **飞行辅助开关**：设置面板「飞行辅助（自动改平）」——关掉后是**纯手动杆**（光标偏移=滚转/俯仰速率，回中保持姿态），不自动改平、不自动修高度，全凭手感；战斗中即时切换。
- **轰炸机遥控尾炮塔**（Tu-22M / B-21）：机尾双管炮塔，按 `T` 开关自动炮手——**附近（330m 内）有敌机就打**（就近优先，打中过我的优先反击），没有敌机才扫射地面坦克，**防空坦克（ZSU-23-4）最优先**；敌方/友军 AI 轰炸机的尾炮常开（别死咬轰炸机六点）。
- **世界大战防空坦克**：敌坦克 18% 概率出 ZSU-23-4 速射防空（玩家高档房一半换成美系 **M163 火神**——转管速射 0.072s/发、装甲 45/32/22、极速 40m/s，射速/装甲/速度全面压制 ZSU）——尾炮手与你的头等大事。M163 亦可在科技树 🇺🇸 线研发（Rank 6）。
- **AI 射击纪律**：全体 AI（坦克/飞机/直升机/尾炮手）开火前查视线——被建筑/岩石/山脊挡住、目标在烟里，一律不泼弹药；直升机火箭/导弹同样不隔楼硬扔。
- **空战分房（战雷式）**：敌我 AI 出机与坦克同款三档分房——同级为主(55%) + 高一档(30%) + 高两档班长机(15%)；敌方直升机 rank 限玩家+1（R1 房不出 AH-64），波次模式随波次爬 rank。
- **空战全地图**：夜战/雷暴/雨天/峡谷/海岛等 10 张图照飞（自动跳过纯巷战图——街区建筑只进坦克地形）；夜/雨的天空雾距已按空战适配，高空一样淋雨。
- **坠机跟拍回放**：空战击落敌机，右上角小窗环绕跟拍真机身坠落（尾焰拖烟/直升机螺旋解体/触地爆炸）；终局最后一杀切全屏 0.4x 慢放。
- **坦克模块化损伤**：履带(减速)/炮管(哑火)/发动机(减速)/弹药架(殉爆)/起火，HUD 显示损坏模块，自动修复。
- **地形起伏**：噪声高度场＋**宏观地形域**——同一张图内调制出平原/丘陵/山区（山区带大丘陵，图内高度差可达 70m+），坦克贴地行驶、弹丸依地形爆炸、飞机撞山坠毁；顶点色（绿谷棕峰）。战场：陆战 900m 半径 / 空战 1600 半径（穹顶随图放大），雾距放宽；**太阳/阴影跟随玩家**（远处不再"无影区/边缘闪烁"）。坦克机动整体放缓（12 m/s，钢铁巨兽的节奏）。
- **载具外观**：梯形后掠上反角机翼、流线座舱、螺旋桨整流罩、加力焰、翼尖灯、翼下挂架；Canvas 迷彩涂装；坦克加减速俯仰/转向侧倾 + 履带差速滚动。
- **天空**：渐变天穹 + 散落云团。
- **AI**：坦克交战绕环带机动（22~46m 切向绕侧翼、远距斜接近、近距斜脱离），炮塔独立瞄准+弹道下坠补偿，240m 内交战、打飞机会算提前量拦截解；抢点冲进圈驻守；卡死自动倒车甩头脱困；低血倒车撤退，飞机低血侧滑规避；敌方/队友按队伍区分强弱。
- **炮击手感**：主炮曳光（叠加发光长光条）、开炮后坐（欠阻尼悬挂弹簧——猛冲→过冲→回稳 ~0.5s；摇晃方向跟炮管走：朝前打抬头、侧面打侧倾；相机被推后+磕头，瞄准镜里震得更狠）。
- **战场态势**：`M` 大地图（地形底图+敌我+三点）、`Tab` 战绩板（AI 车组代号、击杀日志、票数）。
- **巷道通行**：城镇/工厂街道宽度按"楼最大跨+坦克直径+余量"生成，任何街区之间都开得过去；据点周边自动留空。
- **无尽模式**：随击杀数递增难度（敌方变多变硬），每 10 击杀出一只精英 Boss（大体型、高血高伤）。
- **小地图**：玩家居中朝上，敌红/友蓝点。
- **损伤可视化**：起火焦化冒黑烟，喷气机高空拉白色凝结尾迹。
- **移动端触控**：左半屏虚拟摇杆驾驶，右半屏拖动瞄准、按住开火。
- **进度系统**：打仗赚 💰金币 / 🔬研发点，科技树解锁更多载具。
- **国家锁定**：出战页默认锁定当前载具的国家（🏳 按钮可切"全部"），车库太大也一眼选完——本局只从一个国家出车。
- **三选一强化（波次类模式）**：每清一波弹 3 张战术卡（装填提速/附加装甲/敌军迟滞/车顶武器站…15 张池），点击或按 1/2/3 选择，局内无限叠加——每局 build 都不一样。
- **车顶自动炮台（空投奖励）**：无限弹药模式下首个空投必得车顶遥控机枪塔（自动索敌+视线纪律，空投可升到 Lv3 双管）；有限弹药模式空投改为补满备弹。
- **Boss 连战**：目标循环新玩法——每波 1~2 只 Boss（血量逐波攀升）+ 递增护卫，6 波起双 Boss。
- **夺旗冲锋**：南北基地各一面军旗（直上光柱信标），夺敌方旗带回己方基地得分；敌军也会偷你的旗（拦截carrier！），先夺 3 次获胜。
- **动态战斗音乐**：三层合成器（平静琶音→战鼓→进行曲低音），强度随交战实时升降（近敌升温/交火激战）；连杀琶音、王牌警报、空投风铃、波次号角、终局号令；设置面板有音乐音量。
- **打击感**：击毁轻震屏；敌人**受损可视化**——半血冒灰烟、残血拖黑烟（坦克/飞机通用，战斗状态一眼可读）。
- **战绩册（📊 战绩）**：每局战绩入册（胜负/击杀/波次/命中率/时长），总场次、总击杀、胜率、单局纪录破纪录结算面板金色播报。
- **日常任务（轮换合同）**：每天按日期发 3 个——**29 种任务池**（击杀弹种/距离/尾炮/王牌/Boss、无伤胜局、命中率、夺旗/Boss连战/每日挑战/世界大战/夜战雨战、空投拾取、强化卡、直升机/陆空模式击杀……），战斗内实时累计进度，完成自动发奖。
- **每日挑战**：日期种子定死模式/地图/词条（同一天人人同布局），波次生存撑到第 5 波 +800💰（每天首通一次），记录本地最佳波次。
- **敌方王牌**：无尽/波次模式定期登场（专属代号+强化属性+暗红涂装），击毁悬赏 +300💰。
- **曲射炮（抛物线弹道）**：Boss 攻城炮与美系 **M109 圣骑士**（科技树 Rank 3）共用一套曲射机制——45° 抛物线、落点红圈警告（敌方射向我方时）；**伤害语义：被直接命中或处于爆炸范围（13m）内 = 大额杀伤——玩家发射的曲射炮弹<b>一炮毙命</b>（artyOneShot），敌方/Boss 曲射=减一半血**（红圈可躲）。**玩家驾驶 M109**：准星方向 12° 锥内自动锁定敌方**坦克**（**不限距离，隔全图也能锁**，30° 宽锥粘性跟踪；**不锁飞机/直升机**——导引头同样只咬地面目标）；炮弹**自带跟踪系统**——①导引头：没锁住/目标中途阵亡时，下落段自动捕获瞄准点附近 90m 内最近敌接管追踪（不用瞄得很准）；②末段制导：下落段修正弹道直扑目标，**移动目标必中**。红橙环=拦截点指示。左键发射，长装填；最小射程 30m，薄装甲——远远地锁、远远地轰，别贴脸。
- **空投补给（随机事件）**：战场上空随机降落补给箱（绿烟信标），驶入/飞近拾取随机增益：高效装填 / 发动机增压 / 战场抢修 / 弹药补给（限时 25s，到期自动还原）。

## 运行方式

> ⚠️ 本游戏用 ES module + importmap，必须经 **HTTP 服务器** 访问，**不能直接双击 `index.html`**（`file://` 下浏览器会拦截 module 加载）。
> 桌面 app（Electron）已自带本地 HTTP 服务器，正常从启动器打开即可；独立调试请起本地服务器：

```bash
cd warthunder-game
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

Three.js 已随包附带（`three.module.js`，r160 ESM），**无需联网**。

## 操作

> 鼠标为**自由光标**（不做指针锁定），载具 / 炮塔跟随光标，准星贴在光标上。
> 坦克炮塔为战争雷霆式**指哪打哪**：高追随率跟随光标，光标到哪儿炮塔就跟到哪儿（不再慢吞吞一直转）。

| 鼠标移动 | 指哪飞哪（飞行教官自动改平 / 转弯，无需手动操纵俯仰滚转） |
| `W` / `S` | 加 / 减油门 |

| 鼠标右键 / `X` | 导弹（仅喷气机，6 发、自动回充，会追踪锁定目标） |

| `L` | 投核弹（仅 B-21，消耗 3 颗炸弹，超大范围毁灭） |
| `Esc` | 暂停 / 继续 |
| `F` | 灭火（起火时使用） |

击毁全部敌方目标（耗尽其票数）即胜利；玩家命数（默认 4 条）耗尽即失败。
**征服模式**（陆战/世界大战可开）：占领 A/B/C 三点，占 2 点敌方票数 2/秒流失、占 3 点 5/秒；击杀/阵亡每车扣 50 票；敌方增援与票数挂钩（票未尽援不断），先耗尽对方 500 票者获胜；敌方全灭且增援断供 6 秒即判胜（防卡局）。AI 会冲进点内驻守抢点。

## 目录结构

```
warthunder-game/
├── index.html          # 页面 + importmap + <script type="module" src="./js/main.js">
├── js/main.js          # ★核心：CONFIG / 实体 / AI / Game 引擎 / 音效 / 设置 / 菜单入口
├── js/lib.js           # 工具与资源生成器：clamp/lerp/lerpAngle + 云/天穹/迷彩/履带纹理 + terrainHeight
├── js/mp.js            # 联机对战（PvP）：大厅 / 幽灵同步 / 主机权威伤害（依赖由 main.js 注入）
├── three.module.js     # Three.js r160 ESM（本地附带，离线可用）
├── css/style.css       # 菜单与 HUD 样式
├── package.json        # npm start（起本地服务器）/ npm run check（语法检查）
└── README.md
```

> 历史上这里曾有过 `js/Game.js`、`js/entities/` 等多文件 + 内联打包的双份结构，现已收敛为 `js/main.js` + `js/lib.js` 两个 ESM 模块统一维护（用原生 ESM + importmap，无需打包）。

## 嵌入到你自己的 app

最简单：把整个目录丢进你的静态服务器即可（桌面 app 用自带本地服务器加载 `index.html`）。

`Game` 是 `js/main.js` 里的核心引擎类，构造参数（供阅读源码 / 二次开发参考）：

```js
const game = new Game({
  canvas: myCanvas,          // 必填：用于渲染的 <canvas>
  mode: 'tank',              // 'tank' | 'plane'
  hudContainer: hudDiv,      // 必填：HUD 会注入此容器
  onExit: () => { ... },     // 可选：玩家点"返回主菜单"时回调
});
```

- `Game.dispose()` 会解绑所有事件监听、释放渲染器，方便在 app 里销毁。
- 平衡性参数全在 `js/main.js` 顶部的 `CONFIG`，改数值即可调难度。
- 调试：实例挂在 `window.__game`；URL 加 `?auto=tank` / `?auto=plane` 可跳过菜单直接开局（冒烟测试用）。

## 技术说明

- **性能（不降画质的流畅四件套）**：`powerPreference:'high-performance'` 强制独显（双 GPU Mac 默认可能落核显——"性能好也卡"的头号原因）；画质自适应防抖（换档冷却 20s＋连续差评才降档，阴影贴图开局定死永不中途重建——重建=GPU 同步大停顿）；着色器开局预热（`renderer.compile`，战斗中不再"首次遇到新材质卡一下"）；**静态障碍合批**（楼/岩石/矮墙/废墟按材质合并，200+ mesh → 个位数，draw call 与阴影 pass 大幅缩减）。

- Three.js r160，ESM + importmap（r150 起官方不再提供 UMD 全局构建）。
- 载具用基本几何体拼搭（车体/炮塔/炮管、机身/机翼/尾翼），无需美术资源。
- 命中判定为**扫掠式球体碰撞**（上一帧→当前帧线段 vs 命中球，取最早进入目标——真实弹速 750m/s 每帧 12.5m，点位采样会整辆车隧穿）；弹道为真实量级（炮口速 615~915 m/s、重力 9.81，穿深随距离衰减）；飞行模型为街机式（速度沿机头 + 低速下沉）。
- 起火载具会焦化冒黑烟，喷气机高油门高空时拉白色凝结尾迹。
